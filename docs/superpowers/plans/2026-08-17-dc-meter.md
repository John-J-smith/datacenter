# dc_meter 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `dc_core` 之上实现电表 Profile `dc_meter`：六大类静态表、`alias` 访问、电量累加、清零、init/tick 胶水；变量类跳过 RAM CRC16，其余带 RAM 镜像的类启用。

**Architecture:** Meter 只调用 `dc.h` 公开 API；`alias`→`dc_id` 在 meter 内解析；各类用编译开关裁剪。依赖已完成的 Core 计划 `2026-08-17-dc-core.md`。

**Tech Stack:** C99、CMake、Host 测试；链接 `dc_core`。

**规格依据:** `docs/superpowers/specs/2026-08-17-embedded-datacenter-design.md` §7

## Global Constraints

- **不兼容**旧 API：无 `ReadAliasData`/`genre`；统一 `alias`
- `dc_meter_read/write` 的 `len` = **成员个数**（内部换算字节再调 `dc_read`/`dc_write`）
- 电量类默认只读（累加走 `dc_meter_add_energy`）
- 变量类块：`DC_BLOCK_SKIP_RAM_CRC`；其它有 RAM 镜像的类：`DC_BLOCK_RAM_CRC16 | DC_BLOCK_NOINIT`
- 不得调用 core 内部符号（`dc_block_*`、`dc_policy_*` 等）
- 每大类可 `METER_CLASS_xxx=0` 裁剪
- 先完成 Core 全量测试再开始本计划

### Task 2: Alias 编解码

**Files:**
- Create: `meter/src/dc_meter_alias.c`
- Create: `tests/host/test_meter_alias.c`

**Interfaces:**
- 位域（固定写死，测试锁定）：

```text
bit31-28: class (0=energy … 5=record)
bit27-16: subclass
bit15-0 : index / attr
```

- Produces: `dc_ret_t dc_meter_alias_to_id(dc_alias_t a, dc_id_t *out_id);`  
  查各类映射表；失败 `DC_METER_ERR_ALIAS`（以 `dc_ret_t` 返回负码）。

`dc_id` 段约定：

| class | id base |
|-------|---------|
| energy | `0x00010000` |
| demand | `0x00020000` |
| param | `0x00030000` |
| variable | `0x00040000` |
| list | `0x00050000` |
| record | `0x00060000` |
