# dc_core 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现领域无关的嵌入式数据中心核心库 `dc_core`：静态表驱动的 ID 读写、格式转换、块级策略、统一介质/OS 端口，以及 RAM CRC16 + noinit 失败后从存储器恢复。

**Architecture:** 扁平 Item 注册表 + 块级策略引擎；公开 API 统一加锁；Host 侧用假介质跑单元测试（CMake + CTest）。电表六大类不在本计划内（见 `2026-08-17-dc-meter.md`）。

**Tech Stack:** C99、CMake ≥3.16、Host 编译（MSVC 或 MinGW/GCC）、无动态内存分配、无第三方依赖。

**规格依据:** `docs/superpowers/specs/2026-08-17-embedded-datacenter-design.md`

## Global Constraints

- 无 `malloc`/`free`；表与配置只存指针
- 公开头不得出现电表/业务符号
- `dc_read`/`dc_write` 的 `len` 为**字节数**
- 策略只配在 **block** 级
- RAM 校验：`[payload | uint16_t LE CRC16-CCITT]`；标志 `DC_BLOCK_RAM_CRC16` 启用
- 锁宏：`DC_LOCK_NONE` / `DC_LOCK_CRITICAL` / `DC_LOCK_MUTEX`（测试默认 `NONE`）
- 介质统一 `read`/`write`/`erase`；不得按 EE/FRAM/Flash 拆多套公开 Port API
- 每个 Task 结束须可编译并通过该 Task 相关测试后再提交

### Task 7: 块存储 + RAM CRC16 + 从介质恢复钩子

**Files:**
- Create: `src/core/dc_block.h`
- Create: `src/core/dc_block.c`
- Create: `tests/host/test_ram_crc_recover.c`
- Create: `src/policy/dc_policy.h`（先定义 ops 结构，NONE 的 load/store 可在本 Task 内联最小实现供测）

**Interfaces:**
- Consumes: `dc_crc16_ccitt`、`dc_media_t`、假策略 load
- Produces:
  - `dc_ret_t dc_block_ram_check_or_recover(dc_block_t *blk);`
  - `void dc_block_ram_update_crc(dc_block_t *blk);`
  - `dc_ret_t dc_block_read_payload(...);` / `dc_block_write_payload(...)`（内部用）

RAM 布局：`ram_cache[0 .. size-1]` 为 payload，`ram_cache[size]`、`ram_cache[size+1]` 为 CRC16 LE。  
`dc_block_t.size` = payload 字节数；调用方分配 `size+2`。

- [ ] **Step 1: 写失败测试**

1. 准备 NV 假介质中有合法 payload+介质头（先用 NONE：介质上存 `size+2` 含介质 CRC 或仅 payload——**v1 NONE：介质存 payload，无额外头；RAM 侧另存 CRC**）
2. 正确填充 RAM + CRC，`check_or_recover` → `DC_OK`
3. 破坏 RAM CRC 字节，介质仍正确 → 调用后 RAM 恢复且 CRC 正确
4. 再破坏介质 → `DC_ERR_CRC`

- [ ] **Step 2: 实现 check/update；恢复时调用 `policy->load` 填入 payload 再 `update_crc`**

若块无 `DC_BLOCK_RAM_CRC16` 或置了 `SKIP_RAM_CRC`：`check_or_recover` 直接 `DC_OK`。

- [ ] **Step 3: PASS + Commit**

```bash
git commit -m "feat(core): RAM CRC16 check and recover from media"
```
